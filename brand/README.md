# Floreo brand

Floreo, by Altiora Technologies. *Floreo* is Latin for "I flourish", from Belize's motto *Sub Umbra Floreo*.

The mark is an F whose arms are two leaves growing from the stem.

| File | Use |
|---|---|
| `floreo-logo.svg` | The logo: mark and wordmark, on light backgrounds |
| `floreo-logo-white.svg` | The same on dark backgrounds |
| `floreo-logo-altiora.svg` | With "by Altiora Technologies", for the website, documents and decks |
| `floreo-mark.svg` | The mark alone: app icons, avatars, 48 px and up |
| `floreo-mark-small.svg` | The mark for 32 px and below (favicons, tabs): no leaf veins |
| `floreo-glyph-purple.svg`, `floreo-glyph-white.svg` | The leaf F alone, one colour (stamps, embossing, watermarks) |
| `floreo-preview.png` | Everything above at a glance |

The wordmark is Inter Tight SemiBold (tracked -2.8%), turned into outlines so it looks the same everywhere without the font.

Colours: purple `#5B2384` to deep purple `#2E0F45` (the tile), lavender `#D8C3EA` (the second leaf), ink `#1E1028` (the wordmark), green `#5FD068` (the dot; `#7BF583` on dark).

Leave clear space around the logo of at least half the mark's height. Do not stretch it, recolour the leaves, or set the word in another font.
